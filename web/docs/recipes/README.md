# Recipes

Pick the one that matches the task, read it, follow it. Each recipe names the
exact files to create and carries working code lifted from the example routes.

| Recipe | Use when |
|---|---|
| [add-a-page.md](add-a-page.md) | Adding any new screen to the app |
| [fetch-and-mutate-data.md](fetch-and-mutate-data.md) | A screen needs server data, or needs to change it |
| [add-a-data-table.md](add-a-data-table.md) | Showing a list of records with sorting, filtering or paging |
| [add-a-form.md](add-a-form.md) | Collecting input with validation |
| [add-a-dialog-or-sheet.md](add-a-dialog-or-sheet.md) | A task belongs in an overlay rather than its own page |
| [add-a-chart.md](add-a-chart.md) | Visualising a series of numbers |

Every recipe assumes the hard rules in `CLAUDE.md`. Finish with the definition
of done there: `bun run verify`, then `bun run screenshot`, then look at the
image.
